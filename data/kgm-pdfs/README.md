# KGM Otoyol ve Kopru Ucret PDF'leri

Bu klasore KGM web sitesinden indirdiginiz PDF dosyalarini yukleyin.
Admin panelindeki "KGM Senkronizasyon" sayfasindan bu PDF'leri parse edip
sistemdeki verileri guncelleyebilirsiniz.

## PDF Indirme Adresi

https://www.kgm.gov.tr/Sayfalar/KGM/SiteTr/Otoyollar/UcretlerYeni.aspx

## Kullanim

1. Yukaridaki PDF'leri KGM sitesinden indirin
2. Bu klasore koyun
3. Admin paneli > KGM Senkronizasyon sayfasina gidin
4. "PDF'leri Yukle ve Parse Et" butonunu kullanin
5. Verileri kontrol edip onaylayin

Alternatif olarak CLI'dan: `npm run sync-tolls`
